## 📊 S&P 500 Stock Clustering & Portfolio Risk Analysis

This project focuses on analyzing stocks listed in the S&P 500 index to identify patterns and group similar stocks using clustering techniques.

The dataset is derived from:
https://en.wikipedia.org/wiki/List_of_S%26P_500_companies

Keywords: Machine Learning, Clustering, Portfolio Optimization, Risk Management, S&P 500

### 🎯 Objective
The main objective is to cluster stocks based on key financial metrics:
- Return
- Beta
- Volatility

These metrics help in understanding stock behavior and risk levels.

### 💡 Motivation
Investing in stocks with different beta values can reduce overall portfolio risk. Beta reflects how sensitive a stock is relative to market movements, making it a key factor in diversification.

By grouping stocks with similar characteristics, this project aims to:
- Identify patterns in stock performance
- Support portfolio diversification strategies
- Enable better risk management decisions

### 🏢 Dataset
The S&P 500 index consists of 500 large-cap U.S. companies from various sectors, listed on NYSE and Nasdaq. Due to its broad market representation, it serves as a reliable dataset for financial analysis and machine learning applications.

### ⚙️ Approach
- Data collection and preprocessing
- Feature selection (return, beta, volatility)
- Clustering using machine learning algorithms (e.g., K-Means)
- Visualization and interpretation of clusters
